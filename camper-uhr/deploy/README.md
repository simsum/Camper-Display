# Installation auf dem Raspberry Pi

Die aktuelle Anleitung steht in [DIETPI.md](DIETPI.md).
Das frühere automatische Setup passte nicht zur heutigen DietPi-Konfiguration
und aktivierte ein Overlay-Dateisystem. Es wird nicht mehr automatisch ausgeführt.

Die beiliegenden systemd- und Kiosk-Dateien sind Vorlagen. Pfade, Benutzer,
Displayanschluss, Drehung und Chromium-Optionen müssen zur eigenen Hardware passen.
Historische Einmal-Migrationen sind nicht Bestandteil einer neuen Installation.
