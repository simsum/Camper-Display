# Beispiel-Screenshots

Die PNG-Dateien wurden im Browser aus den Produktionsmodulen aufgenommen,
bei 1480 × 320 Pixeln. Sie sind echte Renderings, keine grafischen Nachbauten.
Alle Daten stammen aus `frontend/js/public-preview.js` und sind fiktive,
reproduzierbare Beispiele. Aufnahme: Oktober 2026.

Mit dem lokalen Entwicklungsserver folgende Adresse öffnen:

`http://127.0.0.1:8080/public-preview.html?screen=panorama`

Für weitere Ansichten `screen` auf `led`, `flip`, `weather`, `sun`, `calendar`
oder `photos` setzen. Für die native Auflösung den Browser-Inhaltsbereich auf
1480 × 320 einstellen. Bei anderen Größen skaliert die Vorschau proportional.
Die Seite ruft keine privaten APIs ab und speichert keine Einstellungen.

Die Bildmotive stammen aus den eigenen Projektassets. Urheber-/Lizenzangaben
stehen in [THIRD_PARTY_NOTICES.md](../../../THIRD_PARTY_NOTICES.md).
Die Screenshots dieser Galerie enthalten kein Wikimedia-Beispielfoto.
